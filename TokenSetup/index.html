TokenSetup

Här sparar du GitHub-tokenet en gång för alla appar på samma GitHub Pages-domän.

Kontrollerar om token redan finns...

Vad kontrolleras?

När du klickar på Kontrollera och spara token gör sidan tre kontroller innan något sparas:

  1. GitHub godkänner tokenet.
  2. Tokenet kan komma åt repository tomaslennefors/Data.
  3. Tokenet kan skriva till Data. Testet skriver en liten kontrollfil i Data/Test/TokenSetup/TokenCheck.txt.

Tokenet sparas bara om alla tre kontrollerna lyckas.

Så lägger du till eller byter token

  1. Skapa eller kopiera ett giltigt GitHub-token.
  2. Klistra in tokenet i fältet ovan.
  3. Klicka på Kontrollera och spara token.
  4. Vänta tills sidan visar Token godkänt och sparat.
  5. Om ett token redan fanns sparat ersätts det först när det nya tokenet har klarat kontrollen.

Var lagras tokenet?

Tokenet sparas i webbläsarens localStorage för domänen tomaslennefors.github.io, under namnet ChessApps_GitHubToken.

Det lagras alltså lokalt i just den webbläsarprofil och på den enhet där du sparar det. Det skrivs inte in i den publika HTML-filen och skickas inte till andra användares webbläsare.

När måste tokenet matas in på nytt?

  • Om du klickar på Ta bort token.
  • Om du rensar webbplatsdata/localStorage för tomaslennefors.github.io.
  • Om du använder en annan webbläsare, en annan webbläsarprofil eller en annan enhet.
  • Om webbläsarprofilen tas bort eller återställs.
  • Om du använder privat/inkognito-läge och den privata sessionens lagring försvinner när sessionen avslutas.
  • Om GitHub-tokenet går ut eller återkallas. Då måste ett nytt giltigt token kontrolleras och sparas här.

Att bara rensa vanlig webbcache behöver normalt inte ta bort localStorage. Det är framför allt när webbplatsdata/cookies och lokal lagring rensas som tokenet försvinner.
