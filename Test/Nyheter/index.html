HämtaNyheter

När du trycker på Spara önskemål: fritexten sparas som aktuellt önskemål och läggs i fritext-historiken; nya länkar delas automatiskt upp i YouTube-länkar och övriga länkar, dubbletter tas bort och tidigare länkar behålls; allt sparas lokalt i denna webbläsare och i den privata filen Data/Test/Nyheter/HamtaNyheter.json; slutligen kopieras det aktuella önskemålet (fritext + alla sparade länkar) till Urklipp. Rutan Nya länkförslag töms efter en lyckad sparning.

Sorteringsnummer: 1 sorteras först, 2 därefter osv. Lämna tomt eller 0 för att inte använda fältet vid sortering. Datum sorteras nyast först; textfält A–Ö.

Tangentbord: ↑ / ↓ = föregående/nästa rubrik · Mellanslag = starta vald YouTube-video.

Nyhetsfilen ligger publikt tillsammans med appen på GitHub Pages. Filter, sorteringsordning, favoriter och arkivering sparas bara lokalt i respektive webbläsare. Ägardelen HämtaNyheter visas endast för en webbläsare vars GitHub-token har åtkomst till det privata Data-repot.
